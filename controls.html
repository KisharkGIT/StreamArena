HOW TO USE

GETTING STARTED

Download StreamArena from github.com/KisharkGIT/StreamArena. Click the green Code button and select Download ZIP. Extract it anywhere on your PC.

Open StreamArena.exe to launch the server. The server is a small local program running in the background that powers all your overlays — it reads your Snip file, serves every overlay to Streamlabs, and handles all the settings. Keep it open the entire stream or everything will stop working.

Each overlay is a browser source URL you add in Streamlabs. You can copy any URL directly from the STREAMLABS URL copy button inside each widget — click it and it copies to your clipboard.

PROFILES

Profiles let you save completely separate configurations for different streams — one for tournament nights, one for casual sessions, etc. Every setting, widget layout, API token, and overlay config is stored per-profile and switches instantly.

The profile selector lives at the top of the sidebar. Click PROFILE to open the dropdown and switch, create, rename, export, or delete profiles. The active profile name is shown in green next to the button.

  • New Profile — create a blank profile or duplicate an existing one as a starting point.
  • Rename — click the pencil icon on any profile row to edit the name inline. Press Enter to confirm.
  • Export — click the download icon on any row to save that profile as a .json backup file.
  • Import — click ↑ IMPORT at the bottom of the dropdown to load a previously exported profile. It creates a new profile from the file and switches to it automatically.
  • Delete — click the trash icon. The last remaining profile cannot be deleted.

On first run with no existing profiles, StreamArena generates a Default profile automatically.

WHAT YOU'LL NEED

Node.js — required to run the server. If you don't have it, download and install it from nodejs.org. Just install the LTS version and you're good.

Snip — a small app that watches what's playing on Spotify and writes the song info to a text file on your PC. The server reads that file every 2 seconds to power the music overlay.

  • Download and run Snip, then set it to output to a .txt file somewhere on your PC.
  • Point Snip File Location in General Settings to that file.
  • The server also writes a second file called current_spotify_song.txt in the same folder — this is the cleaned-up version after overrides have been applied. You can point a Streamlabs text source at this file if you want the song name to appear as a scrolling ticker on stream.
GENERAL SETTINGS

All stream overlay widgets live under Widget Settings. There are three tabs at the top: General, Widgets, and Preview.

  • Global Font — sets the font used across every overlay at once. Drop .ttf or .otf files into the fonts/ subfolder and they appear here automatically. Hit Update Fonts to refresh the list after adding files.
  • Widget Visibility — toggle switches that show or hide individual widgets from the layout. Turning a widget off hides it from the Widgets tab but does not delete its settings. Turn it back on to restore it.
  • Snip File Location — path to the snip.txt file written by the Snip app. The server reads this every 2 seconds to power the music overlay. Set this before the music overlay will work.
  • Stream Notes — a private notepad only visible in this panel. Use it for shoutout lists, match schedules, or anything you need to reference mid-stream. Never shows on stream.
  • Load Save Data — at the top of Widget Settings there is a LOAD SAVE DATA button. Clicking it re-fetches all saved settings from the active profile and fills every field. Settings load automatically when the panel opens, but use this button if something looks out of sync.
WIDGETS
MUSIC SETTINGS

Music Settings controls the now-playing song overlay that pops up when a song changes.

  • Corner Position — choose which corner of the screen the card appears in.
  • BG Opacity — how opaque the card background is. 0 = invisible, 1 = solid black.
  • Show Duration — how many seconds the card stays visible before hiding.
  • Slide In / Out — toggle animated slide transitions on or off.
  • Song Name Overrides — if you want to fix incorrect Spotify metadata, go to Music Settings and add an Override. Copy the raw text from your Snip file, paste it as the raw value, then provide the correct title and artist.
  • Song Override Output File — by default, current_spotify_song.txt is written to the same folder as your Snip file. Set a custom path here to write it somewhere else instead — useful if a Streamlabs text source is already pointing to a specific location.
  • Test Popup — triggers the card to appear so you can preview it without changing songs.

Add this to Streamlabs as a browser source: http://localhost:7777/overlay

SLIDESHOW

BRB Slideshow — a cycling display shown during your break.

  • Folder Location — point this to a folder and every image, GIF, and video inside gets added to the cycle automatically.
  • Manual File Links — add individual files from anywhere on your PC that aren't in the folder.
  • Timing — set how long images, videos, and GIFs stay on screen. Videos can play their full length or be capped.
  • Randomize — shuffle slide order on each reload.
  • Transition — choose between Fade, Slide, Zoom, or Wipe between slides.

Add this to Streamlabs as a browser source: http://localhost:7777/brb

COUNTDOWN

Countdown — a standalone countdown timer overlay.

  • Set the time using the slider or type it directly as mm:ss.
  • Use Start, Stop, and Reset to control it mid-stream from this panel.
  • The timer turns red in the final minute.
  • Enable Include in BRB slideshow to have it appear as a slide in the BRB rotation.

Add this to Streamlabs as a browser source: http://localhost:7777/countdown

CLOCK

Clock — a live clock overlay.

  • Set a label like "Be Right Back" that appears above the time.
  • Choose 12-hour or 24-hour format.
  • Enable Include in BRB slideshow to add it to the BRB rotation.

Add this to Streamlabs as a browser source: http://localhost:7777/clock

SOCIAL MEDIA

Social Media — a card showing your Twitch, Twitter, and Discord handles.

  • Set a custom message and your handles. Leave any field blank to hide it.
  • Enable Include in BRB slideshow to add it to the BRB rotation.

Add this to Streamlabs as a browser source: http://localhost:7777/social

NEXT MATCH

Next Match — shows the upcoming match on screen so viewers know who is up next.

  • Fill in Player 1, Player 2, and Round. The overlay updates live as you type — no save button needed.
  • Sublabel is an optional second line below the round name (e.g. "Best of 3").
  • You can also push this data automatically from the Start.gg widget — select a set and click Send to Next Match.

Add this to Streamlabs as a browser source: http://localhost:7777/nextmatch

INTEGRATED APPLICATIONS
START.GG

The Start.gg widget connects to your tournament bracket on start.gg and pulls live set data so you can see match results and push upcoming sets to the Next Match overlay — all without leaving the control panel.

Step 1 — Get your API token

  • Go to start.gg and log in to your account.
  • Click your profile icon in the top right, then go to Settings.
  • Scroll down to Developer Settings and click it.
  • Click Create new token, give it a name, and copy the token it generates.
  • Paste it into the API Token field in the Start.gg widget and click Save Token.

Step 2 — Enter your tournament URL

  • Go to your tournament on start.gg and copy the URL from your browser. It will look like https://www.start.gg/tournament/your-tournament-name.
  • Paste it into the Tournament URL field.
  • Click Fetch. The widget will load your events and phases automatically.

Step 3 — Browse and use set data

  • Select an Event and Phase from the dropdowns that appear after fetching.
  • The set list shows all matches in that phase with player names, round names, and scores.
  • Use Show Completed to toggle finished sets on or off.
  • Click any set to select it, then click Send to Next Match to push those player names and round info directly to the Next Match overlay.
  • Sets refresh automatically every 10 seconds once a tournament is loaded. You can also click Fetch at any time to refresh manually. Use the Auto-refresh sets every 10s checkbox to pause automatic updates if needed.
BLUESKY

The Bluesky widget lets you post replay MP4 videos directly to your Bluesky account from the control panel. Select a file, fill in the post title, preview it, and post — the upload runs in the background so you can keep streaming.

Step 1 — Create an App Password

You must use an App Password, not your main Bluesky password. App Passwords are separate login keys that can only be used for posting — they cannot change your account settings or password.

  • Log in to Bluesky on the web or in the app.
  • Go to Settings → Privacy and Security → App Passwords.
  • Click Add App Password, give it a name like "StreamArena", and click Create App Password.
  • Copy the password shown — it looks like xxxx-xxxx-xxxx-xxxx. You will not be able to see it again after closing that screen.

Step 2 — Log in from the widget

  • In the Account section, enter your Handle — this is your Bluesky username, like you.bsky.social.
  • Enter the App Password you just created in the App PW field.
  • Click Login to Bluesky. If it succeeds, your handle will appear as confirmed. Your login is saved automatically and persists between sessions — you only need to log in once.

Step 3 — Set up your replays folder

  • Put the MP4 replay files you want to post in a folder on your PC.
  • By default, only files whose names contain Replay appear in the list — this keeps unrelated MP4s out of the way. You can change this keyword or disable the filter entirely using the Filter by keyword toggle below the folder path.
  • Enter the folder path in Replays Folder and click Scan. The list will show all matching files sorted newest first.

Step 4 — Post a replay

  • Click a file in the list to select it.
  • Fill in the Post Title. You can use these variables and they will be replaced automatically with data from the Next Match widget:
    • P1 — Player 1 name
    • P2 — Player 2 name
    • MATCH — Round label
    Example: P1 vs P2 | MATCH | MMA Tournament
  • Click Preview and Post. A preview modal will show how your post will look on Bluesky, including your profile picture, the resolved title, and a video preview.
  • Click Post to Bluesky in the modal to start the upload. A progress bar tracks the upload — video processing on Bluesky's end takes about 30–60 seconds. The upload runs in the background and will complete even if you close the preview window.
DISCORD OVERLAY

The Discord widget shows who is in a voice channel on stream, with profile pictures, names, and speaking indicators. There are three modes: Group 1, Group 2, and Solo. Group 1 and Group 2 are independent overlays that each track their own channel — useful if you want two separate voice groups visible at once. Solo gives you two individual slots (S1 and S2) where you pin specific members by name.

Step 1 — Create a Discord Application

The overlay connects through a Discord application you register yourself. This is free and only takes a few minutes.

  • Go to discord.com/developers/applications and click New Application.
  • Give it any name, then open the OAuth2 tab from the left sidebar.
  • Copy the Client ID and Client Secret — you'll need both.
  • Under Redirects, add exactly: http://127.0.0.1:7777/discord-auth
  • Save changes.

Step 2 — Connect from the widget

  • Open the Discord widget and expand the Account section.
  • Paste your Client ID and Client Secret into the fields.
  • Click Connect to Discord. A browser window will open asking you to authorize the app — approve it. Your credentials are saved and you won't need to do this again unless you change the app.

Step 3 — Select your channel

  • After connecting, a channel dropdown appears. Select the voice channel you want to display. The overlay will update in real time as members join, leave, or speak.
  • Group 1 and Group 2 each have their own channel selector — set them independently.
  • For Solo mode, select the channel first, then assign a member to Slot 1 and Slot 2 from the dropdowns that appear.

Style Settings

  • Design — choose between Square (boxed cards) or Modern (rounded pill style).
  • Colors — set the background, text, and highlight (speaking indicator) colors.
  • Name Size — slider to control how large the name text appears.
  • Custom Card Width — constrain how wide each member card gets. Useful for keeping things compact when names are long.
  • Name Alignment — align the name text left, center, or right within its card.
  • Server Username — when on, shows the member's server nickname. When off, falls back to their account username with the first letter capitalized.
  • Server PFP — when on, shows the member's server-specific avatar if they have one. When off, uses their main account avatar.

Add these to Streamlabs as browser sources:

  • Group 1: http://127.0.0.1:7777/discord-overlay
  • Group 2: http://127.0.0.1:7777/discord-overlay-2
  • Solo Slot 1: http://127.0.0.1:7777/discord-overlay-solo?slot=s1
  • Solo Slot 2: http://127.0.0.1:7777/discord-overlay-solo?slot=s2
CHAT ENGAGEMENT
LINKING YOUR YOUTUBE ACCOUNT

The Chat Engagement tab connects to your YouTube live chat so StreamArena can read viewer votes for the Live Poll and post automatic replies for Chat Commands. To do this you need a Google OAuth credential — a key you generate yourself that lets StreamArena talk to YouTube on your behalf. This only takes about 10 minutes to set up and you only ever do it once.

What can this access do?

The YouTube scope used here (youtube) gives access to your YouTube channel only — not Gmail, Drive, billing, or anything else on your Google account. The most damaging thing it could do is post or delete chat messages and comments on your channel, or change video visibility. It cannot delete your channel, change your Google password, or access any other Google service. In practice the access token lives only on your local machine in your profile file and the server only accepts connections from 127.0.0.1, so nothing from the internet can reach it. If you ever want to cut access, go to myaccount.google.com → Security → Third-party apps with account access and revoke StreamArena instantly.

Step 1 — Create a Google Cloud Project

  • Go to console.cloud.google.com and sign in with your Google account.
  • At the top of the page, click the project selector dropdown — it will say "Select a project" or show an existing project name next to the Google Cloud logo.
  • In the popup that opens, click New Project in the top-right corner. Do not use any wizard shortcuts like "Deploy an application" or "Create an agent" — those are for different purposes.
  • Name it anything you like (e.g. StreamArena) and click Create.
  • Wait a few seconds for the project to be created, then make sure it is selected in the dropdown before continuing.

Step 2 — Enable the YouTube Data API

  • Click the hamburger menu (three lines) in the top-left corner if you don't see the sidebar.
  • Go to APIs & Services → Library.
  • Search for YouTube Data API v3 and click the result.
  • Click Enable. The page will reload and show a "Manage" button — that means it's active.
  • This step is required before the scope will appear in later steps — if you try to add the YouTube scope without enabling the API first, the search will return nothing.

Step 3 — Set up the OAuth Consent Screen

This is the screen your browser shows when you authorize StreamArena to access YouTube. You only see it once.

  • In the left sidebar under APIs & Services, click OAuth consent screen. If you're using the newer Google Cloud UI, this may appear as Branding in a section called Auth in the sidebar.
  • Select External for User Type and click Create.
  • Fill in the App name (e.g. StreamArena) and your email address for the support contact. Everything else is optional.
  • Click Save and Continue to get to the Scopes screen. In the newer UI, Scopes may be called Data Access in the left sidebar — click that instead.

Step 4 — Add the YouTube Scope

The scope controls exactly what YouTube actions StreamArena is allowed to perform.

  • On the Scopes / Data Access screen, click Add or Remove Scopes.
  • In the search box, type youtube. If nothing appears, go back and make sure you completed Step 2 — the API must be enabled first.
  • Check https://www.googleapis.com/auth/youtube — this is the full YouTube scope and is required for the bot to post chat command responses. If you only want poll vote reading and don't need chat replies, you can use youtube.readonly instead, but command responses won't work.
  • Click Update, then Save and Continue.

Step 5 — Add Yourself as a Test User

While the app is in Testing mode (which is fine — you never need to publish it), only accounts you explicitly list can use it.

  • In the sidebar, click Audience (or continue to the Test Users step in the wizard).
  • Under Test users, click + Add Users and enter the Google account email address you stream with.
  • Save. You won't need to add anyone else — this is your personal tool.

Step 6 — Create OAuth Credentials

  • In the sidebar, click Clients (or Credentials in the older UI) → + Create Credentials → OAuth client ID.
  • Set Application type to Web application.
  • Under Authorized redirect URIs, click + Add URI and enter exactly: http://127.0.0.1:7777/youtube-callback
  • Click Create. A popup shows your Client ID and Client Secret.
  • The Client ID is the long string ending in .apps.googleusercontent.com. The Client Secret is a shorter string starting with GOCSPX-. Copy both — use the copy icon next to each value, or click the edit/pencil icon on your credential to see the full values at any time.

Step 7 — Connect in StreamArena

  • Go to the Chat tab in Widget Settings.
  • Click YouTube Account to expand the dropdown.
  • Paste your Client ID and Client Secret into the fields. They save automatically as you type.
  • Click Connect YouTube. A browser window opens showing Google's sign-in / consent screen. Sign in with your YouTube account and click Allow.
  • The browser will redirect back to StreamArena automatically. The status indicator in the YouTube Account section will update to show your channel name.
  • Start or join a YouTube live stream, then click Find Broadcast to connect StreamArena to the live chat. You can test this with an unlisted stream — the API works identically regardless of stream visibility.
  • Once a broadcast is found, the poll and chat commands are live. The status will confirm the live chat is active.

You only do this once. Your access token is saved locally in your profile and refreshes automatically. On future sessions StreamArena reconnects without asking you to sign in again — just click Find Broadcast when your stream goes live.

LIVE POLL

The Live Poll lets viewers vote in YouTube chat on who will win the upcoming match by typing 1 or 2. Each viewer can only vote once. The results display as two vertical bars on a sidebar overlay in real time.

Setting up portraits

You can display either tournament character art or player avatars at the base of each bar. Switch between modes using the CHARACTER / AVATAR toggle.

  • Character mode — click Load Characters from Tourney to pull the character roster from your active Start.gg tournament. Character images are fetched automatically. Click a character in the P1 grid to assign it to Player 1, and the P2 grid to assign Player 2.
  • Avatar mode — type the Start.gg gamer tags for P1 and P2 and click Fetch Avatars. StreamArena searches the tournament participant list and pulls their profile pictures.

Running the poll

  • After assigning portraits, click Open Poll. The overlay becomes visible and starts counting votes immediately. The mock preview in the panel updates every 3 seconds so you can watch the numbers live without switching windows.
  • Click Close Poll when voting is done. The overlay fades out and stays hidden until the next poll is opened.
  • Opening a new poll always resets the vote counts. You cannot reopen a closed poll and retain its votes.

Add this to Streamlabs as a browser source: http://127.0.0.1:7777/poll-overlay

Size it as a tall narrow strip on the side of the screen — it is designed for portrait/sidebar layout.

CHAT COMMANDS

Chat Commands let you define !commands that StreamArena watches for in your YouTube live chat. When a viewer types a command, the bot automatically posts the response you configured. This requires YouTube to be connected and a broadcast to be found.

  • In the Chat Commands card, click + Add Command.
  • In the left field, type the command exactly as viewers will type it — include the ! prefix (e.g. !bracket).
  • In the right field, type the response the bot will post in chat.
  • Add as many commands as you need, then click Save. Commands are saved to your profile and load automatically next session.
  • Commands are case-insensitive — !Bracket and !bracket both trigger the same response.
  • To remove a command, click the X button on its row and click Save.
BITLY DOWNLOAD COUNTER

The Bitly Download Counter displays a live click count from a Bitly short link as an overlay on stream. Use it to show download counts, view counts, or click counts for any link you've shortened through Bitly. The number animates upward like a clock when it changes.

Step 1 — Get a Bitly API token

  • Log in at app.bitly.com and click your profile icon in the top-right.
  • Go to Account Settings → API.
  • Enter your password and click Generate token. Copy the token shown.

Step 2 — Configure in StreamArena

  • Paste the token into Bitly API Token.
  • Paste your short link into Bitly Link — just the short part, like bit.ly/xxxxxx, without https://.
  • Choose a label from the dropdown: Downloads, Clicks, or Views — this appears above the number on the overlay.
  • Click Test Fetch to confirm the count loads correctly before going live.

Add this to Streamlabs as a browser source: http://127.0.0.1:7777/bitly-overlay

The count refreshes every 30 seconds automatically.

OTHER
THE REPLAY POSTING WORKFLOW

Start.gg, Next Match, and Bluesky are built to work together as a pipeline so your tournament data flows from the bracket into your overlays and posts without retyping anything between them.

  • Start.gg pulls your live bracket. When a match is up, find it in the set list and click Send to Next Match.
  • Next Match receives those player names and round info and displays them on screen for viewers. It also stores P1, P2, and MATCH as live variables that other widgets can read.
  • Bluesky reads those same variables when you build a post title. Put P1, P2, and MATCH in your title template once — after every match, open the Bluesky widget, select the replay, and the title is already filled in correctly with the right player names and round.

The typical flow per set: select the match in Start.gg → send to Next Match → play the set → go to the Bluesky widget → select the replay file → post. No copy-pasting names between windows.

FONTS

Drop any .ttf, .otf, or .woff2 font file into the fonts/ folder next to server.js. Open the General tab in Widget Settings, hit Update Fonts, and it appears in the list. Select it and all overlays switch within 10 seconds.

SHARING / PORTABILITY

To share StreamArena, send them the GitHub link: github.com/KisharkGIT/StreamArena. Downloading from there means they always get the latest version. They'll need Node.js installed. Once set up, they'll need to set their own Snip File Location in General Settings and drop any font files they want into the fonts/ folder. Everything else is self-contained and starts fresh on first run.
